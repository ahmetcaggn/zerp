# Profile Page

The Profile Page is a feature in the application that allows users to view and manage their profile information. It
includes functionalities such as updating personal details, and managing account settings.

## Folder Structure

```
settings/
├── cubit/              # Profile page state management
└── view/               # Profile screen UI
```

## Organization

- **cubit/** - Contains the state management logic for the profile page, including handling user data and interactions.
- **view/** - Contains the UI components and screens for displaying and editing the user's profile information
