# UI Module

Shared UI components, design system, and reusable widgets.

## Folder Structure

```
ui/
├── localization/       # UI-specific localization strings
├── theme/              # App theming and styling
└── widget/             # Reusable UI widgets and components
```

## Components

- **localization/** - UI strings and labels
- **theme/** - Color schemes, typography, and design tokens
- **widget/** - Reusable widgets and component library
