# Product Module

Core application infrastructure and shared utilities supporting all features.

## Folder Structure

```
product/
├── init/               # Application initialization
├── localization/       # Internationalization (i18n)
├── navigation/         # App routing and navigation
├── network/            # Network communication and API
├── service/            # Business logic services
├── storage/            # Local data persistence
└── ui/                 # Shared UI components and themes
```

## Components

- **init/** - App setup and initialization routines
- **localization/** - Multi-language support configurations
- **navigation/** - Route definitions and navigation management
- **network/** - HTTP clients and API communication
- **service/** - Domain-level services and business logic
- **storage/** - Database operations and caching
- **ui/** - Reusable widgets, themes, and design system
